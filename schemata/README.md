## Versioning

- Schema files in this directory (not subdirectories) that use a `v<num>` suffix
  before the extension represent the latest release for that major version.
- Corrections of oversight are treated as patch updates.

> [!IMPORTANT]
>
> If a file is pinned to a schema in this directory (not subdirectories), older
> software components that claim compatibility with that schema version may not
> work correctly with the file.
>
> To avoid this, pin files to a schema under the `permanent/` directory instead.
